동료 제시안 6건과 기존 명세 12건을 대조·병합한 결과다.
**1–6은 두 안이 합쳐진 것**, **7–10은 기존 명세에서 추가로 채택한 것**이다.

# 1. 계단 없는 환승 경로 안내

**통합** — 동료 「계단 0% 최적 환승 경로」 + 다기준 경로탐색 + 실내 3D 라우팅

계단과 에스컬레이터를 배제하고 승강기만으로 이어지는 환승 경로를 계산한다.
소요시간은 보행속도 계수 추정이 아니라 **장애인 실측 환승시간**(`OA-21221`)을 turn penalty로 넣어 산출한다.
여기에 시간·환승수·혼잡·연단위험을 더해 서로 지배하지 않는 3안을 낸다.

- **산출물** — 지도 위 경로 3안(빠른 길 / 편한 길 / 안전한 길), 단계별 승강기 환승 동선 카드, 구간별 부담 프로파일
- **데이터** — dump(`station_master`·`subway_edge`·`edge_time`·`timetable`) · `OA-13290` 환승역 거리·소요시간 · **`OA-21221` 사용자유형별 환승시간** · `OA-12928` 혼잡도 · `OA-22124` 연단정보 · KRiC `transferMovement`·`stationMovement`
- **연산** — 네트워크 위상 생성 → 시간의존 Dijkstra/RAPTOR → 턴·환승 페널티 → 다기준 파레토(MOSP) → 선형참조 라벨링
- **조건** — 「계단 0%」 판정에만 KRiC 키가 필요하다. **나머지 4기준은 키 없이 완성된다.** 키가 나오면 5번째 기준으로 얹는다
- **주의** — KRiC은 좌표를 주지 않는다. 위상(`stMovePath`→`edMovePath`) · 거리(`mvDst`) · 층(`stinFlor`)으로 그래프를 구성한다. 기하가 필요 없으므로 10번에 의존하지 않는다

# 2. 승강기 장애 파급영향 · 당일 점검 안내

**통합** — 동료 「EV 위치 + 당일 점검현황」 + 엘리베이터 장애 파급영향

출구별 승강기 위치와 상태를 지도에 표시해 헛걸음을 막고,
동시에 그 승강기가 멈췄을 때 휠체어 기준으로 **접근 불가가 되는 도시 면적**을 계산한다.
표출이 곧 분석의 입력이므로 두 기능이 데이터를 공유한다.

- **산출물** — 승강기 핀포인트(정상 초록 / 점검중 빨강) + 층수·심도 팝업, **"○○역 EV 정지 → 1.4km² · 8,200명 소실"**, 연간 누적 접근불가 지도
- **데이터** — `OA-15994` 승강기 가동현황 · `OA-22725` EV 위치·운영 · **`OA-21212` EV 좌표(WGS84)** · `OA-22122` 출입구 임시폐쇄 · `OA-22751` 역사 내 공사현황 · `OA-13305` 심도 · 4번의 등시선
- **연산** — 동적 그래프 편집(수직 에지 비용 ∞) → connected components → 재라우팅·최근접 시설 → 등시선 차집합 → 래스터 스택 시계열
- **조건 (게이트 B)** — `OA-15994` 갱신주기가 실시간인가. **「당일」이 이 기능의 핵심이므로 스냅샷이면 what-if 시뮬레이터로 프레이밍을 바꾼다** (임의 역 클릭 → 시뮬레이션). 데모 임팩트는 유지된다
- **주의** — 손실 면적이 4번 등시선의 차집합이므로 **계단 대리변수 처리의 오차를 상속한다.** 숫자와 함께 명시할 것

# 3. 도어별 연단간격 위험도 · 탑승 문 추천

**통합** — 동료 「곡선 승강장 발빠짐 위험 + 휠체어석」 + 연단간격 선형참조 위험도

승강장을 선형 객체로 모델링하고 차량-도어 번호를 M값으로 부여한다.
간격·높이차를 선형 이벤트로 붙이면 위험 구간이 색으로 갈리고,
KRiC의 인접 승강기·계단 차량번호가 붙으면 "승강기와 가장 가까운 칸"이 그대로 꽂힌다.

- **산출물** — 도어별(1-1 ~ 8-4) 연단간격 위험도 다이어그램, **10cm 초과 도어 경고**, 추천 도어 하이라이트, 이동식 안전발판 보관 위치, 발판 요청 필요 여부
- **데이터** — `OA-22124` 연단·곡선구간 · `OA-22531` 차량별 휠체어석 탑승위치 · `OA-22747`·`OA-22498` 안전발판 · `OA-22452` 승강장 형식 · `OA-11572` 역사 길이 · KRiC `stationPlatformTrainDistance`·`stationElevatorCarNumber`·`stationStairCarNumber`
- **연산** — LineString(M) 모델링 → 이벤트 테이블 동적 분할 → `ST_LineLocatePoint` 스냅 → 기하 곡률 계산 → 1번 경로와 네트워크 조인
- **조건 (게이트 C)** — `OA-22124` 「승강장위치」 값이 `1-1`/`3-4` 형태의 도어 번호인가.
  **역당 1행 대표값이면 도어별 다이어그램이 성립하지 않고 역별 위험 등급표로 축소된다**
- **주의** — 승강장 LineString(M) 기하는 주어지지 않는다. 역 좌표 + 승강장 형식 + 역사 길이로 **합성**하며, 합성 기하임을 산출물에 명시한다

# 4. 역세권 안심 보행로 · 도보 등시선

**통합** — 동료 「역세권 휠체어 안심 보행로」 + 실측 도보 등시선

경사 임피던스 그래프 하나에서 두 산출물이 나온다.
**선** — 출구에서 병원·복지관까지 계단과 급경사를 피하고 음성안내 횡단보도로 이어지는 경로.
**면** — 5·10·15분 실제 도달범위. 500m 원에서 이 등시선을 빼면 **허수 역세권**이 나온다.

- **산출물** — 추천 평탄 보행로(초록선) + 음성유도기 위치, 등시선 폴리곤, 허수 역세권 면적과 영향 인구
- **데이터** — `OA-21208` 도보 네트워크 · `OA-22241` 경사도(등고선+표고점) · `OA-21209` 횡단보도 · `OA-22218` 보행신호 음성안내 · 등록장애인 동별 통계 · **목적지 POI(병원·복지관, 확보 필요)**
- **연산** — 위상 구축 → 링크별 DEM 샘플링 → 경사 임피던스 → 서비스영역 등시선 → 알파셰이프 → 버퍼 차집합 → dasymetric mapping
- **조건** — 없음
- **주의** — 도보 네트워크에 **계단 속성이 없다.** 링크 평균 경사 15% 초과를 계단 대리변수로 처리하고, **그 사실을 문서·발표에 명시한다**
- **비고** — 경로 산출이 함께 있어서 평지에서도 결과가 나온다. 7번 비용면 단독으로는 평지에서 전 셀이 「양호」 한 등급으로 나와 지도가 단색이 되는데, 이 기능이 그 한계를 보완한다

# 5. 편의시설 결핍 지도 · 개찰구 내외 탐색

**통합** — 동료 「개찰구 밖 화장실·충전소 탐색」 + 편의시설 결핍 지도

이용자에게는 **개찰구 내/외 · 층 · 출구방면**으로 필터링한 시설 위치를 주고,
같은 인벤토리로 역 단위 2SFCA를 돌려 공급이 부족한 역을 뽑는다.

- **산출물** — 편의시설 토글 필터 + 상세 위치 카드(개찰구 내외 · 층수 · 충전기 대수), 역별 접근성 지수, 우선 설치 후보 리스트
- **데이터** — 서울교통공사 장애인 공중화장실(**개찰구 내·외부·층·상세위치 제공**) · `OA-22741` 장애인 화장실 · `OA-22745` 휠체어 급속충전기 · `OA-22526` 음성유도기 · `OA-22746` 수어 영상전화기 · `OA-22748` 교통약자 도우미 · 노인/장애인 승하차 · 등록장애인 통계 · 4번의 등시선
- **연산** — 속성 필터 → 역 단위 2SFCA → 등시선 캐치먼트 → 면적가중 배분 → 정규화 차분
- **조건** — 없음
- **주의** — **역사 내부 시설에 KDE를 쓰지 않는다.** 시설이 역 안에 있으므로 KDE를 돌리면 "역 위치의 KDE"라는 동어반복이 된다. 공급 단위를 역으로 둔다. 음성유도기·횡단보도 등 **가로에 흩어진 시설만 KDE**로 별도 처리

# 6. 혼잡도 핫스팟 · 쾌적 시간대 추천

**통합** — 동료 「쾌적 승차 시간대 추천」 + 혼잡도 핫스팟

역 × 30분 혼잡 매트릭스에서 요일·시간대별 여유 구간을 추천하고,
같은 매트릭스에 네트워크 가중 공간통계를 걸어 지속 과밀역과 주변 대비 이상치 역을 구분한다.

- **산출물** — 30분 단위 혼잡도 추이 그래프 + 쾌적 탑승 추천 구간, 핫스팟 분류 지도(지속과밀 / 이상치)
- **데이터** — `OA-12928` 1~8호선 혼잡도 · `OA-22197` 9호선 혼잡도 · **`OA-22470` 승객유형별 시간대별 승하차** · **`OA-22483` 노인 시간대별 승하차**
- **연산** — 역×30분 매트릭스 → 네트워크 가중 Getis-Ord Gi\* · Local Moran's I → 노선 선형참조 이벤트 매핑
- **조건** — 없음
- **주의 2건**
  - **`OA-22478`(장애인 월별 승하차)은 월 단위라 시간대 분석에 쓸 수 없다.** 시간대별 교통약자 수요는 `OA-22470` 또는 `OA-22483`으로
  - 공간 가중치를 **유클리드가 아니라 네트워크 인접**으로. 직선거리로 이웃을 정의하면 노선이 다른 옆 동네 역이 이웃이 된다
  - 추세 분석을 하려면 **혼잡도 연도별 파일**을 추가 확보해야 한다. 단일 파일은 대표일 프로파일이라 날짜축이 없다

# 7. 배리어프리 접근 비용면

**기존 명세** — 4번과 9번의 입력이 되는 래스터 엔진.

서울시는 완성된 경사도 래스터를 주지 않고 등고선·표고점만 준다.
이걸 연속 표면으로 보간해야만 하므로 **래스터 GIS가 필수 공정이 된다.**

- **산출물** — 5m 해상도 통행비용 GeoTIFF, 지도 위 반투명 오버레이, 역별 접근 가능 면적
- **데이터** — `OA-22241` 경사도(등고선+표고점) · `OA-21209` 횡단보도 · `OA-22218` 음성유도기 · 보행자 출입구 정보(확보 필요)
- **연산** — TIN/Spline 보간 → Horn 3×3 경사 → 재분류(1/18 · 1/12) → KDE → 지도대수 가중중첩 → 비용거리·LCP → 존 통계
- **조건** — 없음
- **검증 결과 반영 3건**
  1. AHP 인자에서 **「보도폭」을 뺀다.** 도보 네트워크에 폭 속성이 없다 → `경사 · 횡단보도 밀도 · 육교·지하보도 밀도`
  2. 보간은 `griddata(linear)`(TIN)가 아니라 **ANUDEM 계열**(GRASS `r.surf.contour`, `gdal_grid` spline). TIN은 등고선 사이가 평평해지는 terracing 아티팩트로 경사 오차를 키운다
  3. **분석 대상을 구릉지 역세권으로 한정한다.** 평지에서는 전 셀이 「양호」 한 등급으로 나와 지도가 단색이 된다. 산출물명은 **"지형 기복에 따른 통행 부담"** — 연석·단차는 5m 셀 아래라 원리적으로 표현되지 않는다

# 8. 역사 3D 단면

**기존 명세** — 가장 빨리 결과가 나오는 기능. 착수 1순위로 적합하다.

지표 DEM에서 역 표고를 잡고 그 아래로 역사를 심도만큼 익스트루전한다.
승강기 실측 길이·높이를 Z축에 배치하면 수직 이동시설이 어느 층을 잇는지 단면에 그려진다.
평면 길이가 아니라 **3D 길이**를 재는 것이 핵심이다.

- **산출물** — 역별 3D 단면 카드, **"지상 → 승강장 총 하강 27m · 3D 이동거리 82m"** (평면도상 50m가 실제로는 82m)
- **데이터** — `OA-13305` 심도 · `OA-22448` 면적 · `OA-11572` 건축정보 · **`OA-12514` EV·ES 길이·높이** · 7번 DEM
- **연산** — DEM 표고 샘플링 → 3D 익스트루전(deck.gl/CesiumJS) → 3D vs 2D 길이 비교 → 단면 프로파일
- **조건** — 없음. 리스크 없고 난이도 낮음

# 9. 행정동 접근성 대시보드

**기존 명세** — 셀 단위 분석 결과를 정책 언어로 번역하는 층.

7번이 만드는 것은 5m 셀 수십만 개다. 분석 결과지 의사결정 자료가 아니다.
행정동으로 존 집계해 점수로 바꾸고, 수요(장애인 밀도)를 한 축 더해 이변량 코로플레스를 그린다.

- **산출물** — 자치구·행정동 스코어카드, `수요 높음 × 접근성 나쁨` 4분면 우선순위, OD 플로우 맵, GWR 계수 지도
- **데이터** — 7번 비용 래스터 · 등록장애인 성별·연령별·동별 · 서울 생활인구 · `OA-22299` 생활이동 · `OA-21222` 시간대별 OD
- **연산** — 존 통계 → 공간조인 집계 → 이변량 코로플레스 → 플로우 맵 → GWR(행정동 424개, 표본 충분)
- **조건** — 없음
- **주의** — `OA-22656`은 「교통수단별」이 아니라 **외국인** 생활이동이다. 수단별 비교를 하면 외국인 데이터로 분석하게 된다. 내국인은 `OA-22299`

# 10. 역사 안내도 지오레퍼런싱

**기존 명세** — 래스터 GIS를 증명하는 기능이자 1번의 실내 경로 표출 배경.

좌표가 없는 안내도 이미지의 픽셀좌표와 실세계 좌표를 GCP 4~8쌍으로 묶고,
Affine / 2차 다항식 / TPS를 각각 시도해 RMSE가 가장 낮은 것을 채택한다.

- **산출물** — 좌표가 박힌 층별 역사 도면 GeoTIFF, 지도 위 정합 오버레이 + 층 전환 UI, RMSE 리포트
- **데이터** — `OA-11984` 역 이용안내도 · **`OA-21212` EV 좌표(GCP)** · 출입구 좌표 · `OA-22448` 역사 면적
- **연산** — GCP 설정 → Affine/다항식/TPS + RMSE 판정 → 리샘플링 → 월드파일·GeoTIFF → 마스킹·클리핑 → COG 타일 피라미드 → 층별 래스터 스택
- **조건 (게이트 A)** — 안내도가 축척 도면인가 모식도인가.
  **모식도여도 이 기능은 성립한다** — RMSE가 크게 나오는 것을 정직하게 보고하는 것 자체가 유효한 방법론적 결과다
- **주의** — **1번이 이 도면 위에서 거리를 재지 않도록 분리한다.** 모식도 위에서 잰 거리는 물리적 의미가 없다. 1번의 그래프는 KRiC 위상에서 나오고, 이 도면은 표출 배경으로만 쓴다
